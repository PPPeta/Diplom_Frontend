# Diplom_Frontend

Фронтенд-макеты системы управления заказами и сервисными операциями.

## Стек
- HTML / CSS / JavaScript (ванильный, без фреймворков)
- Внешние библиотеки подключаются по необходимости

## Бэкенд (планируется отдельно)
- Python / FastAPI
- PostgreSQL (2 БД) + Redis
- Авторизация: JWT

## Структура
- `index.html` и публичные страницы — публичный сайт
- `client/` — личный кабинет клиента
- `staff/` — внутренняя панель сотрудников (менеджер)
- `executor/` — интерфейс исполнителя
- `admin/` — административный контур
- `assets/css/styles.css` — общая дизайн-система
- `assets/js/app.js` — общий каркас (навигация, топбар, тосты)

## Роли
Гость · Клиент · Менеджер · Исполнитель · Администратор
